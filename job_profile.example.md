# Job profile: what kinds of roles fit you

Fuse scores every new Job Alerts match against the lines below (by meaning, using the
local embedding model, so it costs no LLM tokens) and lists the best fits first.

Copy this file to `job_profile.md` (that copy is git-ignored, so it stays yours) and edit
it. One line per kind of role you want, starting with "- ". Put the role first, then a
few skills or keywords after a colon.

- SAP data scientist: machine learning and analytics on SAP data
- Data engineer or analytics engineer: Python, SQL, dbt, data pipelines, data platforms
- Backend software engineer: Python, APIs, distributed systems, infrastructure
- SAP ABAP developer: ABAP, S/4HANA, RAP, SAP integration
- Python and Django developer: web applications and REST APIs
- AI engineer: LLM agents, RAG, machine learning engineering
